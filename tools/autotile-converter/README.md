# Autotile converter

The autotile converter is part of the Tiled tools:
`tools/importer/tiled/tiledc/autotiles.py`. Run it with `make tiled-assets`
or `tools/scripts/convert_autotiles.sh`. See
[docs/TILED.md](../../docs/TILED.md#autotiles).

`references/` is for reference sheets (for example RPG Maker's autotile
layout) used while working on the converter.
